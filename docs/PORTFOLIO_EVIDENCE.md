# Portfolio Evidence Checklist

Do not market this repository as production Nutanix migration experience until real migrations have been executed.

For credible portfolio evidence, collect:

- release tags and changelog
- CI passing on main
- architecture diagram
- sanitized real RVTools dataset (when legally permitted)
- screenshot/demo of generated assessment
- generated migration-wave artifact
- authorized Prism Central inventory demo
- issue history showing engineering decisions
- security/limitations documentation
- demo video

For genuine production migration evidence, add only sanitized artifacts approved by the employer/customer:
- approved change record
- migration wave count
- number of VMs migrated
- measured cutover durations
- rollback/UAT results
- post-migration handover
